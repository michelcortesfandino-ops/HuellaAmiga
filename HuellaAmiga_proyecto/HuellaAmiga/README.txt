HUELLAAMIGA - PROTOTIPO WEB

Cómo abrir:
1. Descomprime la carpeta.
2. Abre la carpeta huellaamiga desde Visual Studio Code.
3. Abre index.html en el navegador, o instala la extensión "Live Server".
4. Si usas Live Server, pulsa "Go Live" en la barra inferior de VS Code.
5. Para verlo en el celular, conecta el celular y el computador a la misma red Wi-Fi.
   En VS Code, revisa la dirección IP local del computador y abre en el celular:
   http://IP-DEL-COMPUTADOR:5500
   (Live Server debe permitir conexiones de red; si no, usa una opción de publicación como GitHub Pages o Netlify).

QUÉ INCLUYE:
- Bienvenida e inicio de sesión demostrativo.
- Página principal.
- Catálogo de adopciones con filtro por perros y gatos.
- Perfil de cada mascota y botón de solicitud.
- Reportes de mascotas perdidas con formulario.
- Guardados usando LocalStorage.
- Perfil editable.
- Mapa ilustrativo y sección de fundaciones.
- Configuración.

IMPORTANTE:
Es un prototipo académico frontend. Los datos quedan guardados en el navegador del dispositivo
(LocalStorage). No hay base de datos compartida, autenticación real, envío de formularios,
GPS ni mapa interactivo conectado. Para esas funciones se necesita integrar un backend y servicios.
